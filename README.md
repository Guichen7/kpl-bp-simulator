# KPL BP Simulator

2026 KPL 全局 BP 模拟器，内置基于 72 场真实季后赛对局训练的阵容强度评估模型。

## 功能

- **2026 全局 BP 规则**：每队 5 禁用，双轮禁用（2 ban → 3 选 → 3 ban → 2 选）
- **巅峰对决**：BO7 打满 3:3 自动进入盲选局（无禁用、允许镜像阵容）
- **全局 BP 消耗**：系列赛中已用英雄双方锁定
- **AI 实时建议**：每步推荐 3-4 个英雄，理由含版本强度 / 分路匹配 / 协同对 / 克制对 / 被克制警告
- **阵容评分与胜率预测**：BP 结束给出双方 0-100 评分 + 逻辑回归胜率预测
- **真实队伍实力**：可选 10 支 KPL 真实战队（重庆狼队 / 广州TTG 等）
- **官方英雄头像**：127 名英雄全量头像

## 模型说明

数据源为 2026 KPL 夏季赛季后赛 12 个系列赛、72 局完整 BP 记录（虎扑 / 腾讯新闻 / 新浪交叉验证）。

模型组成：
1. 英雄个体强度 —— 经验贝叶斯收缩胜率（m=8）
2. 队伍实力 —— 经验贝叶斯收缩胜率（m=4）
3. 协同对 —— 同队共选高胜率组合（n>=3）
4. 克制对 —— 跨队对位高胜率组合
5. 蓝方效应 —— 逻辑回归（L2 正则，Newton 法求解）
6. 留一交叉验证（LOO-CV）评估

直接打开 `index.html` 即可，零依赖、纯前端。
